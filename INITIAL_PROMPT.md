## Что произойдёт дальше

1. Claude Code прочитает все файлы (~3-5 минут на размышление).
2. Подтвердит понимание + задаст уточняющие вопросы (если есть).
3. Ты отвечаешь "ок, начинай этап 1" → Claude Code инициализирует Next.js.
4. Между этапами — Claude Code останавливается, показывает отчёт, ждёт твоё "следующий".
5. На каждом этапе он сам решает, какого субагента подключить (`supabase-architect` для миграций, `api-builder` для роутов, и т.д.).

## Если что-то идёт не так

- **Claude Code забыл правило из CLAUDE.md** → напомни ссылкой "См. CLAUDE.md §4 И-1".
- **Хочет сократить шаг** → "следуй CLAUDE.md §7, не пропускай миграции/RLS/валидацию".
- **Пытается выдумать структуру БД** → "проверь SPEC.md §2".
- **Использует не тот фреймворк/паттерн** → "см. CLAUDE.md §3 (стек)".
